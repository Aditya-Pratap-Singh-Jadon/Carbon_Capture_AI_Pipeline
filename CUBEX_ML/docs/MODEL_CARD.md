# Model Card — CUBEX E-PINN

## Model Overview

| Field | Value |
|---|---|
| **Name** | E-PINN (Physics-Informed Neural Network for Carbon-Capture Verification) |
| **Version** | 1.0.0 |
| **Architecture** | Multi-head MLP + Optional LSTM temporal encoder |
| **Input** | 26-dimensional physical process vector (X_core ∈ ℝ²⁶) |
| **Output** | 15 physically-derived intermediate quantities |
| **Physics enforcement** | 15 equality residuals + 23 Augmented Lagrangian constraints |

## Intended Use

- Verify industrial carbon-capture process data against governing physics equations
- Compute deterministic carbon-credit estimates (tCO₂e)
- Diagnose physics consistency and flag violations
- Provide epistemic uncertainty estimates (diagnostic)
- Support Q-learning fan speed optimization (control loop only)

## NOT Intended For

- Direct inference from Digital Twin's 7-field telemetry (insufficient variables)
- Fabricating missing sensor readings
- Replacing certified manual verification audits
- Overriding regulatory carbon accounting requirements

## Training Data

- Synthetic dataset generated by `src/carbon_capture/input/synthetic.py`
- 26-variable physics-consistent samples with controlled noise
- No real industrial measurement data included in v1.0.0

## Evaluation

| Metric | Status |
|---|---|
| Physics residuals (15) | Enforced during training and inference |
| Constraint violations (23) | Augmented Lagrangian; logged per inference |
| F_valid | Deterministic: 1 if all constraints satisfied, 0 otherwise |
| Uncertainty | MC-Dropout; diagnostic only; does not modify F_valid |
| Explainability | Gradient saliency; observational only |
